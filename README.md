# AIKEN

### Everything You Want. All in One Place.

AIKEN is a modern, premium e-commerce marketplace designed to provide customers with a smooth, fast and professional online shopping experience.

The platform is being developed to support multiple product categories, customer accounts, shopping carts, wishlists, order management, secure payments and eventually seller/vendor functionality.

---

## 🛍️ About AIKEN

AIKEN is a scalable online marketplace inspired by modern e-commerce platforms such as Amazon, Jumia and Kilimall, while maintaining its own unique identity and shopping experience.

The goal is to create a trusted digital marketplace where customers can:

- Discover products
- Search for products
- Browse categories
- Compare products
- Add products to their cart
- Save products to their wishlist
- Place orders
- Track orders
- Manage their customer account

AIKEN is designed with both desktop and mobile shoppers in mind.

## 🧱 Technology

The current version is built using:

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Google Fonts

No JavaScript framework is currently required.

No backend is currently required for the core front-end experience.

---

## 💾 Data Storage

The current development version uses browser LocalStorage for features such as:

- Shopping cart
- Wishlist
- Customer account information
- Order information

This allows the current prototype to maintain customer data between browser sessions.

A cloud database and backend system are planned for future versions.
